# Fontes do acervo local

Este repositório contém o motor, a interface e resumos autorais de orientação; não inclui os PDFs nem textos integrais. Os dados de referência foram preparados a partir dos 11 livros abaixo (1.505 páginas e 4.188 entradas na distribuição original). Os títulos e conteúdos pertencem a seus respectivos autores e editoras; 3D&T foi criado por Marcelo Cassaro. O projeto é independente, sem afiliação à Jambô Editora.

Coloque os arquivos obtidos por você em `app/livros`, sempre com estes nomes. A importação local verifica os hashes dos PDFs presentes. Para regenerar o índice, use cópias também em `referencias/`; as extrações ficam apenas no computador e são ignoradas pelo Git.
